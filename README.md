# Go_Lang Workspace

This repository contains a collection of Go language examples and mini-projects, organized by topic. Each folder demonstrates a specific concept or feature of Go, with a brief explanation to help you understand the purpose before diving into the code.

## Structure

- **01_hello/**:  
  Introduction to Go. Prints "Hello, World!" to the console, demonstrating the basic structure of a Go program.

- **02_variables/**:  
  Shows how to declare, initialize, and use variables of different types in Go.

- **03_userinput/**:  
  Demonstrates reading user input from the console using standard input functions.

- **04_coversions/**:  
  Explains type conversions and parsing strings to other types (like int, float).

- **05_times/**:  
  Covers working with dates and times, including formatting and parsing time values.

- **06_pointers/**:  
  Introduces pointers, showing how to reference and dereference variables.

- **07_arrays/**:  
  Teaches how to declare, initialize, and manipulate fixed-size arrays.

- **08_slicing/**:  
  Explains slices, a flexible and powerful way to work with sequences in Go.

- **09_maps/**:  
  Demonstrates the use of maps (dictionaries) for key-value storage and retrieval.

- **10_struct/**:  
  Introduces structs, Go’s way of creating custom data types with multiple fields.

- **11_ifelse/**:  
  Shows conditional logic using if-else statements.

- **12_switchcase/**:  
  Demonstrates switch-case statements for multi-way branching.

- **13_loop/**:  
  Explains different types of loops (for, while-like) and iteration patterns.

- **14_func/**:  
  Covers defining and using functions, including parameters and return values.

- **15_methods/**:  
  Introduces methods, which are functions with a receiver, allowing object-like behavior.

- **16_defer/**:  
  Shows how to use `defer` to schedule function calls to run after the current function completes.

- **17_files/**:  
  Demonstrates file input/output operations, such as reading from and writing to files.

- **18_api/**:  
  Builds a simple REST API using Go’s standard library, covering HTTP handlers and routing.

- **19_concurrency/**:  
  Introduces concurrency in Go, demonstrating goroutines and channels for parallel execution and communication.

## Usage

Each folder contains a standalone Go module. To run an example:

1. Navigate to the desired folder, e.g.:
   ```sh
   cd 01_hello
   ```
2. Run the program:
   ```sh
   go run main.go
   ```

## Requirements

- [Go](https://golang.org/dl/) 1.18 or higher
